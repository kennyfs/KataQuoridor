## 4. Tests

### 4.1 Test Descriptions

- **T19 (`testQ4SearchTerminalValues`):** Verifies terminal state utility evaluations in MCTS search. For terminal wins, winner utility must evaluate to `+1.0` and losing utilities to `-1.0`. For draws, alive utilities evaluate to `2/nAlive - 1` (-0.5 for 4 alive seats, 0.0 for 2 alive seats).
- **T20 (`testQ4SearchBookkeeping`):** Verifies search tree invariants: root visit count equals sum of child visits, `sum(valueAvg) == 1.0` to within `1e-6`, total node weight equals sum of leaf weights, and monotonicity of visit counts.
- **T21 (`testQ4SearchExactEndgames`):** Generates 25 positions where a pawn is 1 step away from its goal. Verifies that MCTS search selects the winning move with win probability (`utility[winner] ≈ +1.0`).
- **T22 (`testQ4SearchDeterminism`):** Runs search twice from the exact same position with identical random seed (`numThreads = 1`). Verifies that root visits, child visits, and value evaluations are bit-for-bit identical.
- **T23 (`testQ4SearchSymmetry`):** Verifies 8-symmetry equivariance: running search on a position and its symmetric transform produces matching value distributions and symmetric move selections.
- **T24 (`testQ4SearchCache`):** Verifies `NNEvaluator` cache hits during search, cache hit count increments, and cache consistency across identical positions under symmetric reflections.
- **T25 (`testQ4SearchMultithreading`):** Executes search with `numThreads = 4` across multiple search positions. Verifies race-free execution, node table thread safety, and valid visit distributions under ThreadSanitizer.
- **T26 (`testQ4SearchTreeReuse`):** Plays consecutive moves in search tree (`makeMove`), verifying that the existing subtree is preserved, root visits carry over, and live node count returns to 0 after `clearSearch()` and after destruction.
- **T27 (`testQ4SearchConfigGuards`):** Verifies that `Search::checkParams` rejects prohibited options: non-zero `playoutDoublingAdvantage`, non-zero `staticScoreUtilityFactor`, enabled `useGraphSearch`, enabled `useEvalCache`, and invalid parameters.
- **T28 (Python Integration Tests in `python/tests/test_q4_search.py`):**
  - `test_q4qtp_search_commands`: tests QTP protocol handling for `bot=search`, `q4-search-params`, `q4-analyze [visits]`, `genmove`, `undo`, `eliminate`, and `clear_board`.
  - `test_q4match_rotation`: tests 4-seat rotation in `q4match` with `search:<model>@visits` players.
  - `test_t28_play_matches`: runs 100 games of `search:b2c64@200` vs 3 greedy bots and 100 games vs 3 basher bots with full seat rotation.

### 8.1 Bugs Fixed (A1–A4)

#### Bug A1: Search Tree Node Leaks & Subtree Reuse Memory Corruption
- **Root Cause:** `allocateOrFindNode` allocated nodes via `new` without inserting them into `nodeTable`. `~SearchNode` only deleted child pointers rather than children. `clearSearch()` only freed the root node, and `makeMove()` invoked `deleteAllTableNodesMulithreaded()`, deleting the entire tree rather than preserving reachable nodes.
- **Fix:** Ported KataGo's `allocateOrFindNode` verbatim with table mutex and collision loop (`useGraphSearch == false`). Ported `deleteAllOldOrAllNewTableNodesMulithreaded` and `applyRecursivelyAnyOrderMulithreaded` with node-age marking. Added `liveNodeCount` static atomic counter to `SearchNode`.

For terminal draws `[0,0,0,0,1]`, all alive seats were misclassified as eliminated, evaluating utility to `-1.0` instead of `-0.5`.
- **Fix:** Stored `rootAliveMask` and `rootNumAlive` on `Search` during `setPosition` (eliminations never occur during search, per Plan §8.7). Replaced all value-based heuristics with `rootAliveMask`.

#### Bug A3: Data Race on Node Statistics (`statsLock`)
- **Root Cause:** `SearchNode::statsLock` was declared but never acquired in `addLeafValue` or `recomputeNodeStats`. Concurrently running threads updating averages created lost updates and data races. Additionally, `Search::~Search()` killed threads before clearing the table, violating KataGo lifecycle order.
- **Fix:** Restored `while(node.statsLock.test_and_set(std::memory_order_acquire)); ... node.statsLock.clear(std::memory_order_release);` at all KataGo lock sites. Moved `killThreads()` to the very end of `~Search()`.
- **Failing Run Before Fix:**
  - Command: `./cpp/build-tsan/katago runtests q4search`
