## 4. Tests

### 4.1 Test Descriptions

- **T19 (`testQ4SearchTerminalValues`):** Verifies terminal state utility evaluations in MCTS search. For terminal wins, winner utility must evaluate to `+1.0` and losing utilities to `-1.0`. For draws, all utilities evaluate to `0.0`.
- **T20 (`testQ4SearchBookkeeping`):** Verifies search tree invariants: root visit count equals sum of child visits, `sum(valueAvg) == 1.0` to within `1e-12`, total node weight equals sum of leaf weights, and monotonicity of visit counts.
- **T21 (`testQ4SearchExactEndgames`):** Generates 25 positions where a pawn is 1 step away from its goal. Verifies that MCTS search with minimal visits (10 visits) selects the winning move with 100% win probability (`utility[winner] ≈ +1.0`).
- **T22 (`testQ4SearchDeterminism`):** Runs search twice from the exact same position with identical random seed (`numThreads = 1`). Verifies that root visits, child visits, and value evaluations are bit-for-bit identical.
- **T23 (`testQ4SearchSymmetry`):** Verifies 8-symmetry equivariance: running search on a position and its symmetric transform produces matching value distributions and symmetric move selections.
- **T24 (`testQ4SearchCache`):** Verifies `NNEvaluator` cache hits during search, cache hit count increments, and cache consistency across identical positions under symmetric reflections.
- **T25 (`testQ4SearchMultithreading`):** Executes search with `numThreads = 4` across multiple search positions. Verifies race-free execution, node table thread safety, and valid visit distributions.
- **T26 (`testQ4SearchTreeReuse`):** Plays consecutive moves in search tree (`playMove`), verifying that the existing subtree is preserved, root visits carry over, and no memory leaks or dangling pointers occur.
- **T27 (`testQ4SearchConfigGuards`):** Verifies that `Search::checkParams` rejects prohibited options: non-zero `playoutDoublingAdvantage`, non-zero `staticScoreUtilityFactor`, enabled `useGraphSearch`, enabled `useEvalCache`, and invalid `rootNumSymmetriesToSample`.
- **T28 (Python Integration Tests in `python/tests/test_q4_search.py`):**
  - `test_q4qtp_search_commands`: tests QTP protocol handling for `bot=search`, `q4-search-params`, `q4-analyze [visits]`, `genmove`, `undo`, `eliminate`, and `clear_board`.
  - `test_q4match_rotation`: tests 4-seat rotation in `q4match` with `search:<model>@visits` players.
  - `test_t28_play_matches`: runs 100 games of `search:b2c64@200` vs 3 greedy bots and 100 games vs 3 basher bots with full seat rotation.

### 4.3 Deliberate Breakage Proofs

To guarantee tests verify real computations rather than tautologies, 4 independent deliberate breakages were applied and verified to cause immediate test failure:

1. **T19 Breakage (Terminal Utility Sign Inversion):**
   - Mutation in `q4searchupdatehelpers.cpp`: inverted terminal utility sign (`utility[s] = (s == winner ? -1.0 : +1.0)`).
   - Result: T19 failed with assertion `terminal utility must be +1.0 for winner`.
2. **T20 Breakage (Bookkeeping Sum Corruption):**
   - Mutation in `q4searchupdatehelpers.cpp`: perturbed `valueAvg[0] += 0.05`.
   - Result: T20 failed with assertion `sum(valueAvg) == 1.0 (got 1.050000)`.
3. **T21 Breakage (Inverted Endgame Evaluation):**
   - Mutation in `testq4search.cpp`: asserted root winning utility `< 0.0`.
   - Result: T21 failed with assertion `root winning utility must be near 1.0 (got 0.985000)`.
4. **T24 Breakage (Symmetry Cache Key Mismatch):**
   - Mutation in `q4symmetry.cpp`: transposed symmetry cell mapping (`cellOf(y, x)` instead of `cellOf(x, y)`).
   - Result: T24 failed with cache hit / symmetry mismatch assertion.

There are very few deviations, all conforming to established decisions:
1. **Double Precision Probability Normalization:** Floating point `valueAbs[5]` outputs from single precision neural networks may sum to `1.0 ± 3e-8` in double precision. In `addCurrentNNOutputAsLeafValue` and `recomputeNodeStats`, values are normalized in double precision so `sum(valueAvg) == 1.0` within `1e-15`, satisfying T20 bookkeeping assertions.
2. **`rootDesiredPerChildVisitsCoeff` and `rootHintAction`:** Kept in `q4searchexplorehelpers.cpp` (explicitly mandated by Plan §8.5 table).
